# Picks desktop releases

Official desktop installers and release notes for [Picks](https://www.joinpicks.com).

The Picks application source is maintained separately. This repository contains distribution assets only.

No public desktop release is available yet. Download availability and supported platforms will be listed at [joinpicks.com/download](https://www.joinpicks.com/download) once signed installers have completed release verification.

Installers require a Picks account. Web application deployments and native desktop updates are separate release processes.

For help, contact support@joinpicks.com.
